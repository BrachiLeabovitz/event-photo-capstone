
:הרצת 
 node --version 
 npm install

* **מה עבד?**
  * הרצת הפקודה `node --version` החזירה את הגרסה המותקנת v26.8.1.
  * לאחר מעבר לתיקיית הפרויקט, הפקודה `npm install` רצה בהצלחה והתקינה 160 חבילות (packages).

* **מה לא עבד?**
  * בפתחת התהליך, הרצת הפקודה `npm install` נכשלה עם שגיאת `ENOENT: no such file or directory`. השגיאה נוצרה מכיוון שהטרמינל היה בתיקייה העליונה ולא בתוך תיקיית הפרויקט `event-photo-capstone`, ולכן הקובץ `package.json` לא נמצא.

* **מה היה צריך לשנות/לתקן כדי שיעבוד?**
  * בוצע ניווט לתוך תיקיית הפרויקט המושרשת בעזרת הפקודה `cd event-photo-capstone`, ולאחר מכן הרצה חוזרת של `npm install`.

הרצת:
npm start

* **מה עבד?**
  * הרצת הפקודה `npm start` הפעילה בהצלחה את השרת המקומי בכתובת `http://localhost:3000`.
  * פנייה לנתיב `http://localhost:3000/health` החזירה תשובה תקינה בפורמט JSON: `{"status":"ok"}`.

* **מה נצפה / מה לא עבד?**
  * בפנייה לנתיב הראשי (`/`) בדפדפן התקבלה ההודעה `Cannot GET /`. התנהגות זו תקינה כיוון שהשרת משרת נתיבי API בלבד ואין דף הבית ראשי מוגדר.

* **מה היה צריך לשנות/לתקן כדי שיעבוד?**
  * לא נדרש תיקון בקוד, השרת פעל כראוי.
